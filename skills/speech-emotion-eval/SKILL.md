# 语音情绪评测集

判断使用者现在有什么，交付该阶段的实物。用稳定的样本编号贯穿采录、听审和导出。刚排定的录制任务、已收到的 WAV 和具有有效金标的样本应分别计数。

| 现有输入 | 执行动作 | 本次交付 |
|---|---|---|
| 业务需求，可附场景、候选句或旧表 | 读取[设计与提示词](references/design.md)。设计覆盖与配额，写出全部文本和表演提示，逐条核验。 | 可读的覆盖设计、完整 `collection.csv`、`config.json` 和核验结果。只请求某一部分时取相应结果。 |
| 录音及对应编号或清单 | 读取[听审与复核](references/review.md)。核对编号、可读性、来源及缺件，按配置建立两份独立听审任务。 | 可试听的任务、缺件记录、原始意见。人工听审完成后交付定稿与审计记录。 |
| 已定稿的人工标签、对应音频及接收规范 | 读取[字段与交付](references/delivery.md)。确认金标来源和版本，将样本与音频一一关联，按目标接收端做字段和枚举映射。 | 评分清单及回读结果。接收程序可用时运行一次实际读入并记录证据。 |

1. 从需求推出能确定的内容。无总量时可提出有依据的试采配额，并明确假设。有硬性要求冲突时列出算式，继续完成与两种口径都兼容的工作。
2. 先生成采录内容，再导入实录。新录样本独立保存朗读预设与表演提示。存量录音沿用实际转写，登记来源。同句对照共享文本和说话人，两条音频各有唯一编号。
3. 将文件写入用户的项目目录，用本技能目录下的 `scripts/pipeline.py` 执行相应的 `check`、`audio` 或 `export`。逐行语义复核由执行者完成。遇到确定性错误修正后再次核验。
4. 人工金标来自实际听审或可追溯的外部定稿记录。保留初审分歧、后续修订理由及版本。只有采录材料时金标留空，可评分数量为零。报告实际完成的阶段、可交付文件和缺件。

清单格式和接收端配置见[字段与交付](references/delivery.md)。配套听审工具随完整项目提供，在项目根目录运行 `python run.py demo`。仅使用本技能目录时，仍可生成采录材料、检查音频或导出外部定稿。
